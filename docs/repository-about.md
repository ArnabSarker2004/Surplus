## Longer project summary

Surplus helps students connect everyday spending with the larger question of whether their semester is covered. It combines guided planning, transaction review, editable budgets, goals, scenarios, work schedules, and a curated TMU resource hub. A layered Express backend manages authenticated workspaces, encrypted bank tokens, and staged transaction synchronization. Shared TypeScript calculations enforce consistent financial rules, while a local Python service evaluates forecasting models against a chronological baseline and produces explained cash-flow simulations. The public demo uses fictional data and requires no account, bank connection, or external AI credentials.
